# File Finder

A simple Python tool that searches for files in a directory based on a user-defined keyword.

## 🚀 Features

* Searches through folders and subfolders
* User input for flexible file search
* Case-insensitive search
* Displays full file paths
* Counts total matches

## 🛠️ Technologies Used

* Python
* os module

## ▶️ How to Run

1. Run the script:


python file_finder.py


2. Enter a search term when prompted.
